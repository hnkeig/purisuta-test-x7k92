# 画面まわりの画像を置く場所（タイトル画面・コマンド画面・会話画面）

ここに置いたファイルは、**タイトル画面**のロゴとメニューボタン、
**コマンド画面**の休養・勉強などのボタン、そして
**会話（ノベル）画面**のクイックメニュー・メッセージ枠・名前プレート・顔の写真枠に使われます。
置いていないものは、いままでどおりの絵や文字で表示されます。
**入れたり消したりしたら `python3 build.py` を1回実行してください。**

拡張子は `.png` `.webp` `.jpg` `.gif` `.svg` のどれでもかまいません。

## 2. メニューボタン（土台＋アイコン＋文字の3枚重ね）

ボタン1つにつき、最大5枚を重ねて組み立てます。
真ん中の名前（`newgame` など）でひとまとまりです。

```
ui_title_base_newgame_normal.png   土台（ふだん）              ※これが必須
ui_title_base_newgame_hover.png    土台（カーソルが乗ったとき）
ui_title_icon_newgame.png          左のアイコン
ui_title_label_newgame_ja.png      「はじめから」の文字
ui_title_label_newgame_en.png      「NEW GAME」の小さい文字
```

4つのボタンの名前は、こう決まっています。

| ボタン | 真ん中の名前 |
|---|---|
| はじめから | `newgame` |
| つづきから | `continue` |
| おまけ | `extra` |
| オプション | `option` |

（この対応は `assets/config.js` の `UI_RULE.parts` で変えられます）

### 作るときの決めごと

- **土台は必須。** 土台が無いボタンは、この作りを使いません
- **アイコンと文字は「部品だけ」**を、周りを透明にして切り抜いてください。
  土台と同じ大きさのキャンバスに置く必要はありません
- **大きさは「素材の原寸どおり」に重ねます。**
  土台と同じ縮尺で描いておけば、そのまま合います（`UI_RULE` の `btnIconH` などが `"auto"`）。
  自分で大きさを決めたいときだけ、`"auto"` のかわりに `0.42` のような数を書いてください
- **文字の絵は、上下の余白のとりかたを4つでそろえてください。**
  原寸どおりに重ねるので、余白がちがうと文字の高さがそろいません
- `_hover` `_en`、アイコン、文字は、それぞれ**無くてもかまいません**
  （無いものは出ないだけで、ほかは動きます）
- 「つづきから」はセーブデータが無いとき自動で暗くなります（専用の絵は不要です）

### 目安の大きさ

タイトルは内部座標 1200×675 の画面に描かれ、遊ぶ画面に合わせて拡大されます。
ボタンは画面の横はばの約 30%、ロゴは約 28% で表示されます。

| | 目安 |
|---|---|
| 土台 | 横 708 × 縦 162（いま入っている素材の大きさ。もっと大きくてもかまいません） |
| アイコン | 横 72 × 縦 72 |
| 日本語の文字 | 横 320 × 縦 64 |
| 英語の文字 | 横 320 × 縦 30 くらい |
| ロゴ | 横 1000 × 縦 620 くらい |

**4つとも同じ縮尺で作ってください。**
土台を大きくしたら、アイコンと文字も同じ倍率で大きくします。
（原寸どおりに重ねるので、倍率がちがうと大きさがそろいません）

## 3. むかしの作り（1枚絵）も使えます

土台が見つからないボタンは、こちらに落ちます。

「はじめからだけ3枚重ね、残りは1枚絵」でも、ちゃんと動きます。

## 4. 置き場所の調整

ロゴとボタンの位置・大きさ、ボタンの中のアイコンと文字の置き場所は、
**`assets/config.js` の `UI_RULE`** で決めます。数字はぜんぶ「割合」です。

| | 意味 |
|---|---|
| `menuAlign` | `"left"` 左寄せ ／ `"center"` まんなか ／ `"right"` 右寄せ |
| `menuX` | 画面のはしからの余白 |
| `menuY` | 上下の位置。0＝まんなか。プラスで下へ |
| `logoX` | ロゴだけ左右にずらす（マイナスで左へ） |
| `menuGap` / `btnGap` | ロゴとボタンのすき間 ／ ボタンどうしのすき間 |
| `logoW` / `btnW` | ロゴとボタンの横はば（`〜Mb` はスマホのとき） |
| `btnH` / `btnHMb` | ボタンの高さの上限（絵の形はそのまま） |
| `btnIconX` / `btnIconH` | ボタンの中の、アイコンの左右位置と高さ |
| `btnLabelX` / `btnLabelY` / `btnLabelH` | 日本語の文字の左右・上下位置と高さ |
| `btnEnY` / `btnEnH` | 英語の小さい文字の上下位置と高さ |

位置は**その部品の中心**です。
`btnIconX: 0.119` なら、土台の左から 11.9% のところがアイコンの中心になります。
高さ（`〜H`）は `"auto"` なら**素材の原寸どおり**。数を書けば、そちらが優先されます。

**いまの値は、いただいた素材（土台 708×162）から測って入れてあります。**

| | いまの値 | どこを測ったか |
|---|---|---|
| `btnIconX` | 0.119 | 土台のひし形の中心 |
| `btnLabelX` | 0.495 | 左右の飾りの線のまんなか |
| `btnLabelY` | 0.421 | 帯の上ふちと飾りの線の、まんなか |
| `btnEnY` | 0.657 | 飾りの線と同じ高さ |

`btnGap` が**マイナス**なのは、土台の絵の上下に透明な余白があるためです
（そのままだとボタンどうしが離れて見えます）。絵を作りなおしたら調整してください。

## 5. コマンド画面のボタン（休養・勉強…）

コマンド画面（自室）のボタンも、**このフォルダ**に絵を置くとさしかわります。
ボタン1つにつき2枚です。

```
ui_cmd_study_normal.png   勉強（ふだん）              ※これが必須
ui_cmd_study_hover.png    勉強（カーソルが乗ったとき。無ければ同じ絵）
```

真ん中の名前は、こう決まっています。

| ボタン | 名前 | | ボタン | 名前 |
|---|---|---|---|---|
| 休養 | `rest` | | 入部する | `join` |
| 勉強 | `study` | | 電話 | `tel` |
| 運動 | `sport` | | おでかけ | `out` |
| 芸術 | `art` | | 予定表 | `cal` |
| 流行 | `trend` | | くわしく | `info` |
| 自分磨き | `charm` | | あそび方 | `help` |
| 手伝い | `care` | | きろく | `save` |
| バイト | `job` | | せってい | `cfg` |
| 部活 | `club` | | デバッグ | `dbg` |

- **1つずつ差しかえてかまいません。** 置いていないボタンは、
  いままでどおり絵文字と文字のままです
- ボタンは**正方形**（画面では 80×80）です。**正方形の透過PNG**
  （240×240 くらい）で作ってください
- 押せないとき（予定を立てる日ではない、など）は、その絵のまま暗くなります。
  専用の絵は要りません
- 部活とバイトは、**種類ごと**に変えることもできます（先にこちらを探します）
  ```
  ui_cmd_club_base_normal.png   野球部だけの絵
  ui_cmd_job_conv_normal.png    コンビニだけの絵
  ```
  種類の名前は `assets/config.js` の `CLUBS` / `JOBS` の左側の id です

### 置き場所の調整（`assets/config.js` の `CMD_ICON`）

| | 意味 |
|---|---|
| `label` | 絵にしたボタンの下に、文字（休養・勉強…）も出すか |
| `fit` | 絵の入れかた。`"contain"` 全体を入れる ／ `"cover"` 枠いっぱい |
| `bob` | カーソルが乗ったとき、ふわふわ揺らすか |

## 6. 会話（ノベル）画面の素材

会話画面のクイックメニュー・メッセージ枠・名前プレート・顔の写真枠も、
**このフォルダ**に置きます。置いていないものは、いままでどおりの絵のままです。

### クイックメニュー（画面の右上）

ボタン1つにつき2枚。**正方形**（161×161 くらい）で、絵の中に文字まで入れてください。

```
ui_btn_save_normal.png     ui_btn_save_hover.png      ← きろく
ui_btn_load_normal.png     ui_btn_load_hover.png      ← よみこみ
ui_btn_auto_normal.png     ui_btn_auto_hover.png      ← 自動送り
ui_btn_skip_normal.png     ui_btn_skip_hover.png      ← 早送り
ui_btn_menu_normal.png     ui_btn_menu_hover.png      ← くわしく
ui_btn_config_normal.png   ui_btn_config_hover.png    ← せってい　★これから
ui_btn_title_normal.png    ui_btn_title_hover.png     ← タイトルへ　★これから
ui_btn_close_normal.png    ui_btn_close_hover.png     ← 閉じる（×）★これから

ui_quickmenu_bar.png                                  ← ボタンのうしろに敷く帯（任意）
```

- **`config` と `title` は、まだ置いていなくても場所を空けてあります。**
  それまでは仮のひし形が出ていて、押せば動きます。絵を置けばそのまま入れかわります
- `close` は、メッセージ枠の右上に出る「閉じる（×）」です。
  **右クリックでも同じこと（ウィンドウを消す／戻す）ができます。**
  ×ボタン自体を出したくないときは、`assets/config.js` の `VN_UI.closeBtn` を
  `false` にしてください
- **`ui_quickmenu_bar.png`** は、ボタンのうしろに敷く**よこ長の帯**です（無くてもOK）。
  **右のはしまでのび**、左はいちばん左のボタンより `qmBarLeft` ぶん外へ出ます。
  よこ長（1600×120 くらい）で作り、**左のはしをうすく**しておくと自然につながります
- 大きさと位置は `assets/config.js` の `VN_UI`（`qmSize` / `qmGap` / `qmRight` / `qmTop`）

### メッセージ枠・名前プレート・顔の写真枠

```
ui_dialogue_panel.png   メッセージ枠（2211×328 くらい。よこ長）
ui_nameplate.png        名前のプレート（592×104 くらい）
ui_photo_frame.png      顔を入れる写真の枠（402×505 くらい。窓の中は透明に）
ui_photo_mask.png       写真の窓のかたち（枠と**同じ大きさ・同じ位置**で、窓だけ塗る）

ui_photo_name_kanade.png   写真の右下にのせる、手書きふうの名前　★これから
ui_photo_name_rena.png
ui_photo_name_hinata.png
ui_photo_name_luka.png
ui_photo_name_minamo.png
ui_photo_name_sakuya.png
```

- 枠は**絵の形（よこ÷たて）どおり**に表示されます。縦横比は自由です
- **`ui_photo_mask.png` は、`ui_photo_frame.png` と同じキャンバス**で作ってください。
  窓にしたいところだけを塗りつぶし、まわりは透明にします
  （置かないときは、`VN_UI` の `photoTop` などの数字で四角く切りぬきます）
- ⚠ **窓のかたち（mask）が効くのは `starmate.html`（1ファイル版）だけです。**
  フォルダ版の `index.html` をそのままダブルクリックで開くと、ブラウザが
  この絵を「よその場所のファイル」としてあつかい、読みこめません。
  そのときは自動で、`VN_UI` の `photoTop` / `photoRight` / `photoBot` /
  `photoLeft` による**四角い切りぬき**に切りかわります。
  **この4つの数字も、窓の位置に合わせておいてください。**
  （フォルダ版でも窓のかたちを使いたいときは、簡易サーバごしに開いてください。
  　例：フォルダの中で `python3 -m http.server` → `http://localhost:8000/`）
### ★ いまは「枠を絵に描きこむ作り」です（`VN_UI.photoInImage: true`）

`assets/chara/<キャラid>/bust/<表情>.png` のほうに、
**白い枠と、頭のはみ出しを描きこんで**ください。
ゲームは切りぬきをせず、**その絵をそのまま置く**だけになります。
（このとき `ui_photo_frame.png` と `ui_photo_mask.png` は使いません）

**傾きだけは、ゲーム側でかけます**（`VN_UI.photoTilt`。いま **-4.0°**）。
絵は**まっすぐ**描いておいてください。あとから数字で何度でも変えられます。

| | |
|---|---|
| 大きさ | 横 **1000 × 縦 1300** くらい（もっと大きくてもかまいません） |
| 形式 | **透過PNG**。写真のまわりは透明に |
| 中身 | 白いポラロイドの枠（**まっすぐ**） ／ 窓の中の写真 ／ 枠から出る髪 |
| 影 | 描いても、描かなくてもOK（`VN_UI.photoShadow` を `false` にすると消せます） |

**★ いちばん大事な決まり**

- **表情ちがいの絵は、キャンバスの大きさも、枠の位置も、まったく同じに**してください。
  ずれていると、表情が変わるたびに写真がガタッと動いて見えます
- **絵のいちばん下＝写真のいちばん下**にしてください。画面の下から
  `photoBottom` のところに、絵の下のはしが来ます
- 服ごとに変えたいときは、いままでどおり `bust/<服の名前>/<表情>.png`

**位置と大きさ**（`assets/config.js` の `VN_UI`）

- `photoW`（いま 0.250）… 絵の**横はば**（画面の横はばに対する割合）。
  透明なすきまも入った幅なので、写真が小さく見えるときは少し上げてください
- `photoX` / `photoBottom` … 画面の左と下からの余白
- `photoClear` … 写真と本文のあいだのすき間。**マイナスにもできます**
  （透明なすきまのぶん、本文が離れて見えるときに使ってください）
- `photoTilt`（いま -4.0）… **傾き。いつでもこの数字で変えられます**
- `photoHeadOut` は **0**（頭のはみ出しは絵のほうに入っているので）

まだ枠を描きこんでいない絵を使うあいだは、`photoInImage` を `false` に戻してください。
`false` のときは、下の「枠を別ファイルで重ねる作り」で動きます。

### 枠を別ファイルで重ねる作り（`photoInImage: false` のとき）

- 顔の写真枠は、少し傾けて置かれます（角度は `VN_UI.photoTilt`。0でまっすぐ）
- **頭が写真の枠から、すこしだけ飛び出します。**
  出る量は `VN_UI.photoHeadOut`（枠の高さに対する割合。0.05＝5%）。
  出るのは**窓のはばのぶんだけ**で、白いふちの左右へは広がりません。
  写真の中での顔の大きさ・位置は、いままでどおり `photoFitX` / `photoFitY` です
  （枠いっぱいに収まるように自動で合わせます）。
  ★ これは **`bust/` の顔画像の背景が透明**（切り抜き）であることが前提です。
  　 背景つきの絵だと、四角い写真がそのままはみ出して見えます。
  　 そのときは `photoHeadOut` を 0 にするか、`photoHead` を `false` に
  （立ち絵を切り抜いて使っている子とSVGの子には、飛び出しは付きません）
- **写真枠は、メッセージ枠の上に重ねて置かれます。**
  大きさは `VN_UI.photoW`（画面の横はばに対する割合）だけで決まり、
  たては絵の形なりです。つまり **`photoW` を大きくすると、上へも右へも伸びて**、
  メッセージ枠の上に大きく飛び出します。
  重なったぶんは**自動で本文と名前プレートが右へよける**ので、文字は隠れません
  （すき間をもう少し空けたいときは `photoClear`）

### 写真の右下の名前（`ui_photo_name_<キャラid>.png`）

うしろの `kanade` などは**キャラの id** です（`assets/chara/` のフォルダ名と同じ）。
表示名を変えても、この id は変わりません。

| 名前 | id |
|---|---|
| 桜井 かなで | `kanade` ／ 天堂 玲奈 `rena` ／ 夏川 ひなた `hinata` |
| 月島 ルカ | `luka` ／ 綾瀬 みなも `minamo` ／ 姫野 咲耶 `sakuya` |

- **よこ長の透過PNG**で、**文字だけ**を切り抜いてください（目安 420×150 くらい）
- 枠と**いっしょに傾きます**。まっすぐ描いてかまいません
- 大きさと位置は `VN_UI` の `photoNameW` / `photoNameRight` / `photoNameBottom`
  （ぜんぶ「枠の大きさに対する割合」）
- **置いた子にだけ出ます。** 1人ずつ足していってかまいません

### 置き場所の調整（`assets/config.js` の `VN_UI`）

| | 意味 |
|---|---|
| `qmSize` / `qmSizeMb` | クイックメニューのボタンの大きさ（画面の高さに対する割合） |
| `qmGap` / `qmRight` / `qmTop` | ボタンのすき間 ／ 右の余白 ／ 上の余白 |
| `qmBarH` / `qmBarLeft` | うしろの帯の高さ ／ 左へのばす量 |
| `panelBottom` | メッセージ枠の、画面の下からの余白 |
| `bodyTop` / `bodyH` | 本文が入る帯の、上の位置と高さ（枠の高さに対する割合） |
| `bodyL` / `bodyR` | 本文の左右（枠の横はばに対する割合） |
| `bodyScale` | 本文の大きさ。1＝帯いっぱい |
| `panelAlpha` | 枠の絵の濃さ。1で透けない／小さいほど、うしろの絵が見えます |
| `nameW` / `nameX` / `nameY` / `nameTextX` | 名前プレートの大きさ・位置と、名前の文字の位置 |
| `photoW` / `photoWMb` | **写真枠の横はば**（スマホは `〜Mb`）。大きくすると上へ伸びます |
| `photoX` / `photoBottom` | 写真枠の、左と下の余白 |
| `photoClear` | 写真枠と本文のあいだに、さらに空けるすき間 |
| `photoInImage` | **`true`＝枠まで絵に描きこむ作り**（切りぬきも回転もしない） |
| `photoShadow` | 写真の下に影をつけるか |
| `photoTilt` | 写真枠の傾き（度）。マイナスで左へ（`photoInImage:true` のときは 0） |
| `photoFitX` / `photoFitY` | 写真の中で、顔のどこを見せるか |
| `photoHeadOut` | **頭を枠の上へどれだけ出すか**（枠の高さに対する割合。0で出さない） |
| `photoHead` | `false` にすると、頭を飛び出させません |
| `photoNameW` / `photoNameRight` / `photoNameBottom` | 右下の名前の絵の、大きさと位置 |
| `closeSize` / `closeBtn` | ×ボタンの大きさ ／ 出すかどうか |

## 7. 背景とBGMは別の場所です

| | 置く場所 |
|---|---|
| タイトルの背景画像 | `assets/bg/title.png`（2400×1350 推奨）／**季節べつの4枚**も置けます |
| タイトルのBGM | `assets/bgm/title.mp3` |

くわしくは `assets/README.md` の「4. 背景」「5. BGM」を読んでください。
