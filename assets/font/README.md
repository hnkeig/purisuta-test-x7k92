# 書体（フォント）を置く場所

ここにフォントファイルを **1つ** 置くと、ゲームじゅうの文字がその書体になります。
置いていなければ、いままでどおり端末の標準の書体（ヒラギノなど）で表示されます。

```
assets/font/
    myfont.woff2        ← ふつうの太さ（これだけでOK）
    myfont-Bold.woff2   ← 太字ぶん（任意）
```

**入れたり消したりしたら、かならず一度 `python3 build.py` を実行してください。**

## 使える形式

| 形式 | 拡張子 | ひとこと |
|---|---|---|
| WOFF2 | `.woff2` | **いちばんおすすめ。** 同じ書体でもファイルが小さくなります |
| WOFF | `.woff` | 古いブラウザ向け |
| TrueType | `.ttf` | そのまま置けますが、重くなりがちです |
| OpenType | `.otf` | 〃 |

ファイル名は自由です。差しかえたいときは、**古いファイルを消して新しいものを置く**だけです。

## 太字ぶんを分けたいとき（任意）

ファイル名に `bold` か `700` が入っていると、**太字のときだけ**そのファイルが使われます。

```
myfont.woff2        ← ふだんの文字
myfont-Bold.woff2   ← 太字（見出し・強調）
```

分けなくても動きます。その場合は、1つのファイルで細字も太字もまかないます。

## 大きさに気をつけてください

日本語のフォントは、**1ファイルで 3〜8MB**になることがあります。
1ファイル版（`starmate.html`）はフォントも中に埋めこむので、そのぶん重くなります。

- **`.woff2` を選ぶ**と、`.ttf` の半分以下になることが多いです
- 使う文字だけに絞る「サブセット化」をすると、さらに小さくできます
  （`fonttools` の `pyftsubset` などで作れます）
- どうしても重いときは、フォルダ版（zip）で配ると軽くて快適です

## 権利について

配布するゲームに埋めこむので、**そのフォントを再配布・埋めこみしてよいか**を
かならずライセンスで確かめてください。
Google Fonts（SIL OFL）などは、たいてい埋めこんで配布できます。
